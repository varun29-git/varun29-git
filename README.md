## Current Work

Building neural systems from scratch to understand them properly. Right now that means:

**[VectorCLM](https://github.com/varun29-git/VectorCLM)** — LLaMA-style transformer with Flash Attention, GQA, and RoPE. Custom BPE tokenizer, 50M parameter training curriculum. The point isn't to compete with production models but to know exactly why every architectural choice was made.

**[NNCS-Mamba](https://github.com/varun29-git/NNCS-Mamba)** — Mamba-based controller for a 12-D drone system using CEGIS (Counter-Example Guided Inductive Synthesis). This sits at the intersection of AI and control theory—not just training a neural net but formally verifying safety properties.

**[ampamp](https://github.com/QuantumAmplification/ampamp)** — Python library for quantum amplitude amplification algorithms (Grover, FPAA, OAA, QSVT). Full documentation, test suite, PyPI-ready. The most production-grade thing I've built.

## Learning by Building

**[MambaReview](https://github.com/varun29-git/MambaReview)** — Implementing Mamba 1/2/3, Vision Mamba, VMamba, and Jamba from papers. My way of learning architectures: build every variant, understand the differences.

**[WorldModels](https://github.com/varun29-git/WorldModels)** — Ha & Schmidhuber's 2018 paper: VAE + MDN-RNN + controller. Exploring how agents can reason about structure in the world, not just react to it.
